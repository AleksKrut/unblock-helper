# v1.1.0 — GUI, EXE, единый launcher

## Что нового

- **Полноценный GUI** с вкладками: Обход, Discord, Сервисы
- **Сборка EXE**: `UnblockHelper.bat build` → `dist\UnblockHelper\`
- **Один launcher** `UnblockHelper.bat` вместо 6 bat-файлов
- Исправлен повторный запуск после закрытия (PID, зависшие процессы)
- Переустановка движка, прогресс операций, журнал

## Запуск

1. `UnblockHelper.bat` (или `dist\UnblockHelper\UnblockHelper.exe` от администратора)
2. Установить движок → Запустить обход → Проверить сайты

## Команды launcher

| Аргумент | Действие |
|----------|----------|
| *(без аргументов)* | GUI |
| `build` | Собрать EXE |
| `cli …` | Командная строка |
| `kill` | Завершить зависший процесс |
